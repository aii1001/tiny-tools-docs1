## 📖 О проекте

**BeautyBooking Tools** — набор вспомогательных скриптов для веб-приложения онлайн-записи к косметологу.

Основной скрипт `beauty_check.py` предназначен для:
- ✅ Проверки структуры проекта перед запуском
- ✅ Валидации параметров подключения к базе данных PostgreSQL
- ✅ Тестирования доступности API-эндпоинтов
- ✅ Генерации отчётов о конфигурации для отладки

Проект разработан в рамках курсовой работы по специальности "Информационные системы и программирование".

## ✨ Возможности утилит

- 🔍 **Проверка структуры проекта** — валидация наличия ключевых файлов и директорий
- 🗄️ **Проверка БД** — тестирование параметров подключения к PostgreSQL
- 🌐 **Проверка API** — ping-тест эндпоинтов приложения
- 🎨 **Цветной вывод** — наглядное отображение статусов проверок
- 📝 **Подробный режим** — детализированная информация для отладки
- 🔐 **Поддержка .env** — загрузка конфигурации из файла переменных окружения

## 📋 Требования

### Системные требования

| Компонент | Версия | Примечание |
|-----------|--------|------------|
| **Python** | 3.14+ | Требуется поддержка f-strings и type hints |
| **ОС** | Windows 10+, macOS 10.14+, Linux | Кроссплатформенная совместимость |
| **PostgreSQL** | 15+ | Для проверки подключения к БД |
| **Интернет** | Опционально | Требуется только для проверки API |

### Python-зависимости

Зависимости указаны в файле `requirements.txt`:

```txt
requests>=2.31.0          # HTTP-запросы для API-проверок
